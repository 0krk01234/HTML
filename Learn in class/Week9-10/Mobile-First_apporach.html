แนวคิด Moblie-First

เริ่มออกแบบและเขียน code สำหรับหน้าจอมือถือก่อน จากนั้นเพิ่มเงื่อนไขสำหรับหน้าจอที่ใหญ่ขึ้น

ข้อดี

  • เว็บไซต์โหลดเร็ว
  • เหมาะสำหรับผู้ใช้มือถือ
  • โค้ดเป็นระเบียบ

การใช้งานจริง

ใช้งานร่วมกับ Responsive Design และเป็นมาตรฐานของการพัฒนาเว็บยุคปัจจุบัน
